Connect Four – Blazor Tutorial Project
📖 Overview
This project is based on the Microsoft Learn module Build a Connect Four game with Blazor.
It demonstrates how to use Blazor components, event handling, and state management to build an interactive web game.

🎮 Features
Classic Connect Four gameplay

Blazor component-based architecture

Game board rendering with dynamic updates

Win detection for consecutive streaks

Reset and replay functionality

🛠️ Technologies
.NET 8 / Blazor WebAssembly

C# for game logic

Razor components for UI

CSS for styling

🚀 Getting Started
Clone the repository:

bash
git clone https://github.com/gideonagbavor8/ConnectFour.git
Navigate into the project folder:

bash
cd ConnectFour
Run the project:

bash
dotnet run
Open your browser at https://localhost:5001 (or the port shown in console).

📂 Project Structure
Pages/ – Blazor pages

Components/ – Game board and cell components

Services/ – State management

wwwroot/ – Static assets (CSS, images)

📚 Learning Reference
This project follows the tutorial: [Build a Connect Four game with Blazor](https://learn.microsoft.com/en-us/training/modules/dotnet-connect-four/?utm_source=copilot.com).
